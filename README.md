<a id="english"></a>
## English

An interactive, browser-based application designed to help students practice long division through engaging fill-in-the-blank puzzles. 

The entire application is bundled into a **single HTML file**, making it incredibly easy to share, host, or use completely offline without any server setup.

### ✨ Features

*   **Infinite Practice:** Generates random, complex long division problems (up to 3-digit divisors and 5-digit dividends) on the fly.
*   **Smart Validation (Multi-Solution Support):** The app doesn't just check against one static answer. It dynamically calculates the user's input. If a user finds a mathematically valid alternative step-by-step solution, the app recognizes and accepts it!
*   **Standard Formatting:** Strictly adheres to standard long division formatting, including the proper handling of zero-quotient steps and accurately bringing down digits.
*   **Interactive UI:** Clean, responsive interface with instant visual feedback (green for correct, red for incorrect).
*   **Helper Tools:** Includes "Check Answer", "Clear", and "Show Answer" functionalities to guide the learning process.

### 🚀 Getting Started

#### For Users (No installation required)
Simply download the latest `index.html` file from the [Releases](../../releases) page and double-click it to open it in any modern web browser (Chrome, Edge, Safari, Firefox).

## 中文版

这是一个基于浏览器的交互式应用程序，旨在通过有趣的竖式填空题帮助学生练习长除法（竖式除法）。

整个应用程序被打包成一个**单 HTML 文件**，无需任何服务器配置，即可极其方便地分享、托管或完全离线使用。

### ✨ 功能特点

*   **无限练习：** 实时随机生成复杂的竖式除法题目（最高支持三位数除数和五位数被除数）。
*   **智能验证（支持多种解法）：** 应用不仅会与单一的静态标准答案进行比对，还会动态计算用户的输入。如果用户写出了数学上成立的其他分步解法，应用也能完美识别并接受！
*   **标准排版：** 严格遵守标准的竖式除法书写格式，包括正确处理商中间有零的情况以及准确的数字落位。
*   **交互式界面：** 简洁、响应式的界面，提供即时的视觉反馈（绿色代表正确，红色代表错误）。
*   **辅助工具：** 包含“检查答案”、“清除答案”和“给出答案”等功能，引导和辅助学习过程。

### 🚀 快速开始

#### 面向普通用户（无需安装）
只需从 [Releases](../../releases) 页面下载最新的 `index.html` 文件，双击即可在任何现代网页浏览器（如 Chrome, Edge, Safari, Firefox）中直接打开使用。
